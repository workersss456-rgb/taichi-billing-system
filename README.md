# 工程請款／付款核銷系統

太綺水電／匠人本紀集團內部使用。請款（應收）與付款（應付）共用一套系統。

技術架構：**Node.js + Express + PostgreSQL（Neon）**，部署在 Render。

---

## 前台 / 後台

| | 網址 | 誰能用 | 內容 |
|---|---|---|---|
| 前台 | `/`（index.html） | 全體員工 | 手機號碼辨識身分、填寫申請單、查自己送出的單、列印（不含帳戶） |
| 後台 | `/admin.html` | 財務與主管（密碼） | 全部單據、核簽、登記收付、報表、主檔、操作紀錄、作廢 |

前台看不到銀行帳戶、保留款、扣款、預付與淨額；後端 API 也不回傳，不只是畫面隱藏。
收款帳戶由後台在「登記核簽完成」時自動從主檔帶入；主檔沒有帳戶資料時會跳出視窗要求補上，可選擇是否寫回主檔。

## 功能

- **申請單**：請款／付款兩種模式，四種申請類型（一般工程款、點工費用、材料採購、零用金核銷）
- **手機辨識身分**：前台輸入手機自動帶出姓名，查不到時引導建檔（與叫料系統同一套做法）
- **對象搜尋**：公司名稱或統一編號都能查；查無資料可當場建立，銀行帳戶留給財務填
- **收款帳戶**：核簽時從主檔帶入並存成快照，日後主檔異動不影響歷史單據
- **金額計算**：未稅、稅額（5% 或免稅）、含稅，後端重算，不信任前端數字
- **扣抵項目**：保留款、扣款、預付沖抵，算出實際應收／應付淨額
- **收付紀錄**：一張單可分多次撥款／收款，狀態自動變成「部分收付」或「已完成」
- **照片／憑證**：前端壓縮到 1280px 再上傳
- **列印**：A4 申請單，含五欄簽核（出納會計／總經理／覆核／工務主任／經辦人）與附件照片
- **查詢**：單號、發票號、對象、案場、申請人、日期區間、狀態
- **報表**：未付清單、未收清單（皆含帳齡 30／60／90 天分析）、月結表、CSV 匯出
- **作廢**：軟刪除，填原因後保留資料，可還原；已有收付紀錄的單不能作廢
- **操作紀錄**：建立、修改、狀態變更、收付登記、作廢都留存

## 狀態流程

```
付款：草稿 → 待核簽 → 已核准 → 已排款 ┬→ 部分付款 → 付款完成
請款：草稿 → 待核簽 → 已核准 → 已開票 ┴→ 部分收款 → 收款完成
```
「部分」與「完成」由收付紀錄自動判定，不需手動切換。

## 安裝與啟動

```bash
npm install
DATABASE_URL="postgres://..." ADMIN_PASSWORD="你的密碼" npm start
```
開啟 http://localhost:3000

## 環境變數

| 變數 | 說明 |
|---|---|
| `DATABASE_URL` | Neon 的 PostgreSQL 連線字串（必填） |
| `ADMIN_PASSWORD` | 系統密碼（必填，務必修改） |
| `PORT` | 埠號，Render 會自動注入 |

## 主檔初始資料

第一次啟動時，若 `companies` 資料表是空的，會自動匯入 `seeds/masters.json`
（公司 3、廠商 76、申請人 11、案場 22，來自現行試算表）。之後一律在「主檔維護」頁面編輯，不會再覆蓋。

主檔只能停用、不能刪除，因為歷史單據會引用。

## 目錄結構

```
server.js            伺服器進入點
db.js                資料表結構與主檔匯入
config.js            設定載入
middleware/auth.js   密碼驗證
routes/api.js        全部 API
seeds/masters.json   初始主檔
public/
  index.html         主畫面（新增單據／查詢／報表／主檔）
  print.html         列印申請單
  css/style.css
  js/api.js          共用 API 呼叫
  js/app.js          主畫面邏輯
  js/print.js        列印版面
```

## 目前限制（後續階段處理）

- 單一共用密碼，尚無個人帳號與角色權限，操作紀錄記得到動作但記不到人
- 核簽仍是紙本，系統只做「登記核簽完成」
- 尚未與叫料系統串接（資料表已預留 `order_id` 欄位）
- 舊資料（211 張申請單）尚未轉入
